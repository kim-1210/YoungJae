# YoungJae (영재교육 행사)

## 엑셀 함수 설명

## 📚 엑셀 주요 함수 가이드

### 1. COUNT
* **설명**: 지정한 범위에서 **숫자가 들어있는 셀의 개수**를 셉니다. (문자열이나 빈 셀은 제외)
* **구문**: `=COUNT(범위)`
* **예시**: `=COUNT(A1:A10)` (A1부터 A10까지의 셀 중 숫자 데이터가 입력된 셀의 개수 반환)

### 2. COUNTIF
* **설명**: 지정한 범위에서 **특정 조건에 만족하는 셀의 개수**를 셉니다. (조건은 1개만 지정 가능)
* **구문**: `=COUNTIF(범위, "조건")`
* **예시**: `=COUNTIF(M$78:M$91, "yes")` (M78부터 M91까지의 범위 중 값이 "yes"인 셀의 개수 반환)

### 3. COUNTIFS
* **설명**: 지정한 여러 범위에서 **동시에 여러 조건을 만족하는 셀의 개수**를 셉니다. (다중 조건)
* **구문**: `=COUNTIFS(범위1, "조건1", 범위2, "조건2", ...)`
* **예시**: `=COUNTIFS(H$78:H$91, "김해", M$78:M$91, "yes")` (주거지가 "김해"이면서 동시에 입양 여부가 "yes"인 행의 개수 반환)

### 4. ROUND
* **설명**: 특정 숫자를 **지정한 소수점 자릿수(반올림 위치)로 반올림**합니다.
* **구문**: `=ROUND(숫자 또는 식, 자릿수)`
  * `자릿수 > 0`: 소수점 아래 지정한 자릿수까지 표시 (예: `2`는 소수점 셋째 자리에서 반올림하여 둘째 자리까지 표시)
  * `자릿수 = 0`: 소수점 첫째 자리에서 반올림하여 정수로 표시
  * `자릿수 < 0`: 소수점 윗자리(1의 자리, 10의 자리 등)에서 반올림
* **예시**: `=ROUND(0.32653, 4)` (결과값: `0.3265`)
